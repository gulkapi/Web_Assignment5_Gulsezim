
# Assignment 5 - JavaScript Basics

Student: Gulsezim Kapizova

## Project Description

This project demonstrates JavaScript basics, DOM manipulation,
event handling, form validation, and an interactive To-Do List.

## Technologies

- HTML5
- CSS3
- JavaScript

## How to Run

1. Download or clone the project.
2. Open the project folder in VS Code.
3. Open index.html in a web browser.
4. Open Developer Tools to view console output.
5. Test all interactive features.

## Implemented Tasks

Task 0: First JavaScript script and alert message.

Task 1: Variables, arithmetic operators, and string concatenation.

Task 2: Changing paragraph content using JavaScript.

Task 3: Changing background color and font size.

Task 4: Creating and removing HTML list items.

Task 5: Mouseover and mouseout events.

Task 6: Keyboard events with real-time input display.

Task 7: Form validation with error messages.

Task 8: Interactive To-Do List.

## To-Do List Features

- Add new tasks
- Delete tasks
- Mark tasks as completed
- Display task statistics
- Store tasks in a JavaScript array

## Conclusion

This assignment helped me understand how JavaScript interacts
